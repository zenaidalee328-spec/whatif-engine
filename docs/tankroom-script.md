# TankRoom script (formula from docs/ref3-*: hook with goal+enemy -> But [enemy] -> So you [fix] -> This is a [name])
Demo (12.5 s, implemented): 
1. If you bury a water tank to hide from a tornado, you have a storm cellar.
2. But the first gust rips the hatch off and the rain floods it.
3. So you weld on a sealed steel door. This is an airlock.
Next beats (to write/verify facts before building): But the wind throws debris at the door -> pour concrete over the tank (this is a roof); But the tornado's suction lifts the soil -> bury deeper and anchor with steel posts; But the air runs out -> vent pipe with a filter / air tank (compute volume and CO2 with a python model); But the power dies -> generator / battery; But a tree falls on the entrance -> second exit tunnel; twist: the exit must face away from the storm's path; gag: add a stove, a deck of cards and a goat that steals your bread; end: Congratulations, you have built a panic room.
